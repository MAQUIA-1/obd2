# 디자인 자료 상태

현재 방향: 세로 화면, 흰 배경·미니멀 UI, LF 쏘나타 3D 모델. P는 드래그 회전형 개러지, R은 버드아이뷰의 후방 조향 점선, D는 중앙 정후방 추적 시점이다. 앞바퀴는 제원 기반 Ackermann 근사로 조향하며 바닥·후방 점선과 같은 곡률을 사용한다.

| 자료 | 상태 |
|---|---|
| models/sonata-lf/sonata15.glb | 사용할 사용자 제공 모델. 정적 구조 및 데스크톱 Chromium 표시 확인, 실기기 검증 전 |
| models/sonata-lf/inspection.json | 용량·구조·해시 및 미검증 항목 |
| 차량중심_UI_스토리보드.svg / png | 배치·동작 설명용 과거 개념도. 어두운 스타일과 회전 바퀴는 최종안 아님 |
| vehicle-line-art-concept.svg / png | 자체 제작 스타일 시안, 사용자 미채택 |
| model-candidates/quaternius-comparison.png | 모델 비교용 오프라인 렌더. 사용자 미채택 |
| models/quaternius-normal-car-1/ | 미채택 후보의 출처·검토 이력 |

실제 구현 순서는 쏘나타 모델의 브라우저 로딩·방향·재질 확인 → 흰색 세로 화면 → 버드아이뷰 조향 점선 → 주행 시점·속도 연동 모션이다.

현재 웹 구현과 실행·검증 범위는 [프로젝트 README](../README.md), 제원 출처와 적용 한계는 [차량 운동 모델](../research/차량_운동_모델.md)을 참고한다. 흰 배경·밝은 무광 재질·약한 접지 그림자로 표시하며 실사 스튜디오 반사는 사용하지 않는다.
