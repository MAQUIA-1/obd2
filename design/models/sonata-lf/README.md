# 사용자 제공 LF 쏘나타 모델

원본 `2015-hyundai-sonata.zip`의 `source/sonata15.glb`를 수정 없이 추출했다. glTF 2.0 GLB, 3,166,192바이트, 삼각형 46,462개. 텍스처 10개는 GLB 안에 들어 있어 별도 textures 폴더 없이 로딩 가능한 구조다. 정적 구조 검사 내역과 해시는 inspection.json 참고. 실제 브라우저 렌더링과 스마트폰 성능은 아직 확인하지 않았다.

바퀴 애니메이션은 사용자 요청으로 필수가 아니다. 주차 버드아이뷰에서 조향에 따라 휘는 점선 가이드를 별도로 그린다. 정확한 차량 궤적이 아닌 상대적인 조향 방향 표현으로 계획한다.

압축 파일 안에 출처·라이선스 문서는 없었다. 사용자 제공 원본으로 로컬 개발에 사용하며, 원본 링크·라이선스는 배포 자료 정리 시 별도로 기록한다. 모델의 외형·재질은 아직 수정하지 않았다.
