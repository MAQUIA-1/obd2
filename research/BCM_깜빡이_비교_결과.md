# BCM 깜빡이 비교 시험 결과

- 날짜: 2026-11-19
- 세션: `captures/body-controls-03/`
- 대상: LF 쏘나타 하이브리드, Classic SPP, BCM 7A0 → 7A8.
- 조회: B001~B00A, B00C, B00D의 12개 DID를 순차 읽기.
- 응답 기록: 1383건, 상태 집계 `{'ok': 1383}`. 응답 형식 성공과 신호 의미 검증은 구분한다.

## 수행 내용

모두 OFF → 왼쪽 ON → OFF → 오른쪽 ON → OFF → 비상등 ON → OFF 순서로 사용자 확인을 기록했다. 각 상태의 원시 응답과 스냅샷을 보존했다. 최종 OFF 값을 저장하고 수집 프로세스를 SIGINT로 정상 종료했다.

## 판단

현재 12개 조회 그룹에서 좌우 깜빡이 또는 비상등으로 확정할 신호를 확보하지 못했다. B001·B003 일부 값은 변했으나 OFF에서도 변동하며, 관측된 변화만으로 방향지시등 의미를 지정할 수 없다. 비상등 ON 유지 중 수집된 값에서는 점멸에 대응하는 반복 변화가 관측되지 않았다.

이는 해당 조회 그룹·순차 수집 주기에서의 미확인 결과다. 차량에 신호가 없거나 PID로 조회할 수 없다는 뜻은 아니다. 추가 사용자 조작 반복보다 DID 정의 및 실제 해당 차량 적용성 검토를 먼저 진행한다.

## 근거 및 한계

`events.jsonl`, `transactions.jsonl`, `snapshot-*.json`, `indicator-comparison.json`에 안내·사용자 확인 시각 및 응답을 보존했다. 대화 확인은 정확한 조작 시각이 아니며 전환 경계를 제외해 비교했다. 순차 폴링이므로 짧은 점멸을 놓칠 수 있다. 이전 문 개폐 시험은 `body-controls-01`에 남아 있고 이 보고서에서는 문 신호를 확정하지 않았다.
