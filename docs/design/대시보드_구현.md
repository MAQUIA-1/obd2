# 대시보드 구현

## 모드별 화면

| 기어 | 차량 시점 | 표시 정보 |
| --- | --- | --- |
| P | 드래그로 회전하는 대각선 개러지 | 기어, 연료, 배터리 충전율, 외기온 |
| R | 차량 위 수직 시점과 후방 조향 점선 | 속도, 기어, 조향각 |
| N/D | 중앙 정후방 추적 시점 | 속도, 기어, RPM, HV 배터리 전류, 주행 상태, 외기온, 연료, 배터리 충전율, 냉각수온 |

흰색 세로 배치의 최대 너비는 680px다. 속도는 왼쪽 위에 80~104px로 표시한다. 세로 PRND는 오른쪽 위에 고정하고 현재 기어를 48px로 강조한다. 모든 모드에서 계기와 차량 영역 높이, 기어 슬롯 위치를 유지한다. N/D에서 RPM과 전류는 속도 아래 나란히, 외기온은 기어 목록 아래에 표시한다.

## 차량과 카메라

[LF 쏘나타 원본 GLB](쏘나타_LF_모델.md)를 로컬과 Pages에서 사용한다. 렌더링 시 원본의 검은 유리 재질 두 개에 투과·투명도·깊이 쓰기 설정을 적용한다. 밝은 무광 차체, 옅은 회색 차체 외곽선, 약한 접지 그림자를 쓴다. 렌더러 노출은 1.3, 접지 그림자 농도는 0.14다.

카메라는 0.85초 동안 시선 방향·거리·주시점을 보간한다. P로 도착하면 회전 조작을 활성화한다. 전환 중 기어가 바뀌면 현재 시점에서 새 시점으로 이어서 움직인다. OS에서 모션 줄이기를 켜면 즉시 전환한다.

바닥의 `+` 패턴은 1.2m 간격이며 속도와 조향에 따라 이동·회전한다. 멀어질수록 흰색으로 옅어지고, N/D에서는 전방 페이드 범위가 약 8m에서 24m로 늘어난다. 0km/h, P, 모션 줄이기 설정에서는 바닥 이동을 멈춘다. 움직이는 N은 전진으로 가정한다. 앞바퀴, 후방 점선, 바닥 움직임은 같은 [저속 운동 모델](차량_운동_모델.md)을 사용한다.

## 연결과 차량 정보 표시

대시보드는 연결을 기다리는 상태로 시작한다. 연결 전 계기에는 값이 비어 있고 3D 차량은 기본 시점에 놓인다. 하단에서 연결 상태를 확인하고 어댑터에 연결하거나 해제한다. 개발 중에는 [로컬 화면 미리보기](../development.md#로컬-화면-미리보기)를 사용할 수 있다.

연결 후에는 수신한 값을 사용하며 미수신·갱신 중단 값은 `—`로 표시한다. 주행 상태 문구는 속도·기어·RPM·HV 전류가 들어가는 [상태머신](../vehicle/주행_상태머신.md)으로 계산한다. 회전수와 전류는 동력을 추정하는 입력이다. 실차 주행에서 전류 부호와 판정 임계값을 보정하고 실제 후방 궤적을 검증하는 작업이 남아 있다.

데스크톱 Chromium의 소프트웨어 WebGL에서 차체·조향·화면 전환·디버그 조작을 확인했다. 360×800, 430×932, 720×1280에서 화면 넘침과 런타임 오류가 없었다. 실제 스마트폰·DeX의 렌더링 성능은 검증 전이다. 3D 코드는 지연 로딩되며 빌드에 500kB 초과 청크 경고가 있다.
