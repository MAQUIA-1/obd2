# LF 쏘나타 하이브리드 차량 운동 모델

2026-11-19에 적용한 모델이다. 대상은 국내 2015년식 LF HEV이고 세부 트림과 휠은 확인 전이다. 데모와 실차 화면에 같은 계산을 적용하며 실제 차량의 조향비와 궤적은 보정 전이다.

## 1. 제원과 근거

| 항목 | 적용값 | 근거 및 확실성 |
| --- | --- | --- |
| 축거 | 2.805 m | 현대 LF HEV 제원. 기존 GLB 축거 2.738과 구분 |
| 전폭, 미러 제외 | 1.865 m | 현대 LF HEV 제원 |
| 전/후 윤거 | 1.614 / 1.621 m | 16인치 기본값. 17인치는 1.602 / 1.609 m이며 실제 휠 미확인 |
| 조향비 | 14.3:1 | 현대 북미 2016 LF HEV 제원에서 가져온 근사값. 국내 2015 차량의 랙 부품/조향비 일치 여부 미확인 |

| 바닥 패턴 간격 | 1.2 m | 시각화 설정. 차량 제원 아님 |

출처는 현대가 제작한 문서의 보존본이며 호스팅 사이트 자체의 독자 제원을 사용하지 않는다.

- [현대 Motor America 2016 Sonata Hybrid & Plug-In Hybrid 제원표, 2쪽](https://longtailpipe.com/wp-content/uploads/2015/05/42807_2016_Sonata_Plug_in_Hybrid_Specifications.pdf): 조향비, 회전량, 북미 치수. 인치값은 반올림돼 있으므로 국내 mm 제원을 소수점 이하까지 역산하지 않는다.
- [현대 캐나다 LF HEV/PHEV 카탈로그, 제원표](https://autocatalogarchive.com/wp-content/uploads/2016/10/Hyundai-Sonata-Hybrid-2016-CA.pdf): mm 치수와 14.3:1 조향비. 보존본 검색에서 제원 확인, 원문 직접 열기는 403 응답.
- [현대 국내 LF HEV 카탈로그 보존본, 2018](https://autocatalogarchive.com/wp-content/uploads/2018/03/Hyundai-Sonata-Hybrid-2018-KR.pdf): 같은 LF의 축거 2,805mm, 전폭 1,865mm, 휠별 윤거. 2015년 국내 트림의 직접 확정 자료로 취급하지 않는다.
- [실차 폴링 기록](../vehicle/Classic_폴링_수집_결과.md): 중앙 약 -3.0~-3.1°, 좌측 약 -85°. 이 한 번의 중앙값을 영구 영점으로 자동 적용하지 않는다. 데모의 0°는 보정 후 중앙값을 뜻한다.

북미의 2015 Sonata Hybrid는 이전 YF일 수 있어 모델 연도만으로 제원을 혼용하지 않는다. 조향비·회전량은 LF가 적용된 북미 2016 자료를 선택했다.

## 2. 하나의 계산 체계

좌표는 +X 우측, -Z 전방, 1 scene unit = 1m다. 핸들각 θ(도), 조향비 i, 축거 L로부터:

- 등가 앞바퀴각 δ = θ / i × π/180
- 곡률 κ = tan(δ) / L, 뒤축 중앙 회전 반경 R = 1/κ (직진은 무한대)
- 속도 v = km/h / 3.6, 후진이면 음수
- 이동거리 s = v × Δt, 회전각 ψ = κ × s
- 뒤축 상대 이동 x = (1−cos ψ)/κ, z = −sin ψ/κ. κ가 0에 가까우면 x=0, z=−s
- 앞바퀴는 Ackermann 근사 δ_side = atan(Lκ / (1−x_side κ))로 안쪽이 더 많이 꺾임

후진 점선은 같은 식으로 뒤축 기준 0~3.3m 후진했을 때의 뒤 범퍼 좌우 가장자리 궤적이다. 점선의 폭은 차폭에 좌우 각 5cm를 더한 표시값이며 미러는 포함하지 않는다. 점선 시작은 모델 뒤 범퍼에서 5cm 뒤다. 실제 범퍼 궤적이므로 바퀴 자국과 구분한다.

바닥은 이 뒤축 운동을 누적한 평행이동·회전으로 월드 패턴을 샘플링한다. 0.3배 속도 축소와 30m/s 상한을 제거했다. 예: 36km/h는 초당 10m, 1.2m 패턴 간격을 약 0.12초마다 통과한다. 패턴 좌표만 주기적으로 감아 부동소수점 누적을 줄인다. 이동과 회전을 별도로 축소하지 않는다.

GLB의 앞/뒤 바퀴 중심 z=-1.423737645, +1.314242601을 측정했다. Z/Y는 2.805/2.737980247배, X는 1.614/1.521100104배 정규화한다. 모델의 축거·앞 윤거와 운동 좌표를 일치시키는 표시 보정이다. 실제 차체 모든 지점이나 뒤 윤거를 정밀 복원한 모델은 아니다.

## 3. 적용 범위와 검증

저속·평탄면·타이어 미끄럼 없는 bicycle/Ackermann 근사다. 14.3은 대표 조향비이며 랙의 전 구간 비선형성·얼라인먼트·유격·고속 언더스티어는 반영하지 않는다. 제조사의 35.6ft 회전 **직경**은 외측 타이어 기준이므로 뒤축 중앙 R과 직접 같게 맞추지 않는다.

정차/P는 바닥이 멈춘다. N은 속도만으로 진행 방향을 알 수 없어 기존 데모의 전진 가정을 유지한다. `prefers-reduced-motion`에서는 접근성 설정에 따라 바닥 이동을 생략한다. 숨긴 탭 복귀 시 순간 이동 방지를 위해 한 프레임 Δt는 최대 0.1초다. 따라서 10fps 미만에서는 실제 시간에 비해 이동량이 줄 수 있다.

자동 검증: 핸들 143°→등가 바퀴각 10°, km/h→m/s, 최대각 제한, 좌우 Ackermann 회전 중심 일치, 프레임률별 궤적 일치, 전진/후진 되돌림, 3.3m 후진 시 점선 끝과 바닥 변환의 일치. 실제 주차 궤적 보정이나 스마트폰 성능 검증은 별도다.
