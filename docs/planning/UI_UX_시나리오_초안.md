# OBD Dashboard UI·UX 시나리오 초안

이 문서는 수정 전 가로·카드 중심 구상 기록이다. 현재 화면 조건은 세로로 긴 화면이며, 주차 시 버드아이뷰에서 앞바퀴 조향을 표시한다. 사용자 요청에 따라 중앙 차량·애니메이션을 중심으로 확장한 최신 제안은 [차량 중심 UI 벤치마크 기획](차량중심_UI_벤치마크_기획.md)과 [개념 스토리보드](../../design/차량중심_UI_스토리보드.svg)를 참고한다.

2026-11-19. 현재 기본 PID 9종에서 수신한 11개 항목만 사용하는 제안이다. 구현 전 검토안이며 확정된 제품 사양은 아니다. 기본 화면은 삼성 스마트폰 + DeX 가로 모니터를 대상으로 한다.

## 1. 방향

핵심은 차량 상태에 따라 정보의 크기와 밀도가 달라지는 개인용 계기판이다. 주행 화면과 주차 화면을 각각 저장하되, 속도·기어·연결 상태는 항상 같은 위치를 유지한다. 미니멀한 타이포그래피, 넓은 여백, 주간·야간 색상으로 구성한다.

참고한 원칙은 테슬라의 상태에 따른 차량 정보 영역 변화와 플레오스의 주요 운전 정보와 부가 영역 분리다. 아래 구성은 해당 제품의 화면이나 기능을 재현한 것이 아니라 보유 데이터로 만든 제안이다.

## 2. 표시 데이터

| 데이터 | 화면에서의 용도 |
|---|---|
| 속도 | 가장 큰 숫자 계기, km/h |
| RPM | 숫자와 단순 막대 계기 |
| 기어 P/R/N/D/M | 고정 위치의 큰 기어 표시 |
| 조향각 | 중앙 기준 좌우로 회전하는 핸들 도형과 각도 |
| HV 배터리 SOC | 배터리 잔량 막대와 % |
| HV 배터리 전압·전류 | 하이브리드 상세 카드 |
| 연료량 | 연료 잔량 막대와 % |
| 냉각수 온도 | 보조 수치 카드 |
| 제어 모듈 전압 | '모듈 전압'으로 표기하는 보조 수치 카드 |
| 외기 온도 | 상단 고정 정보 또는 보조 카드 |

기어의 전체 열거값은 기존 해석식에 있다. 이번 정차 캡처의 기어는 P만 확인했으므로 R/N/D/M 전환 UI는 기록과 별도로 데모에서 시험하고, 최종 차량 연동에서 동작을 확인한다. 속도·RPM 역시 정차 0 수신과 실제 주행 변화 검증을 구분한다.

조향각은 핸들 각도를 나타낸다. 타이어 각도나 회전 반경으로 환산하지 않는다. SOC와 연료는 서로 다른 잔량으로 각각 표시한다. HV 전류는 수신 부호와 단위를 보여주며 충전·방전이나 엔진·모터 구동 상태를 확정하는 이름은 붙이지 않는다.

## 3. 실행 시나리오

1. 앱 시작: 마지막 사용 테마·주행/주차 배치를 불러온다. '차량 연결'과 '데모 시작' 중 선택한다.
2. 차량 연결: 연결 진행을 한 영역에서 안내한다. 새 응답을 받은 항목부터 표시하고, 나머지 항목은 '--'로 둔다.
3. P 수신: 주차 화면을 표시한다. 사용자는 배터리·차량 수치를 살펴보고 화면 구성을 바꿀 수 있다.
4. D/R/N/M 수신: 주행용 배치로 바꾼다. 속도·기어 중심으로 정리하고 편집 UI를 닫는다.
5. 정차 중 신호 대기: 속도가 0이 되어도 기어가 D이면 주행 배치를 유지한다.
6. P 복귀: 저장한 주차 배치로 돌아간다. 연결은 계속 유지한다.
7. 연결 중단: 화면 상단에 연결 끊김과 다시 연결 버튼을 표시한다. 마지막 수치를 현재 값처럼 유지하지 않는다.

'주차 화면'은 P에 따른 화면 배치이며 시동 OFF, 주차브레이크, READY 상태를 판정하는 기능이 아니다. R에서도 속도·기어와 조향 정보를 보이는 주행 배치를 사용한다.

## 4. 주행 화면

가로 화면을 세 영역으로 나눈다.

| 왼쪽 약 35% | 가운데 약 40% | 오른쪽 약 25% |
|---|---|---|
| 큰 속도 + km/h | RPM 계기 또는 핸들 각도 | 사용자 보조 카드 3개 |
| 기어 | 선택한 집중 항목 | 예: SOC / 연료 / 냉각수 |

상단에는 연결 상태·외기 온도·시각, 하단에는 화면 전환과 주간/야간 테마 버튼을 둔다. 시각은 단말기 시각이며 차량 데이터와 구분한다. 속도·기어는 배치를 바꿔도 같은 위치에 남긴다.

기본 프리셋 제안:

- 기본: 큰 속도 / RPM / SOC·연료·냉각수.
- 하이브리드: 큰 속도 / SOC와 HV 전압·전류 / RPM·연료·외기온.
- 간결: 큰 속도 / 기어·RPM / SOC·연료만 표시.

주행 화면의 조작은 준비된 배치 전환과 테마 변경 정도로 줄인다. 상세 카드 선택·크기 편집은 주차 화면에서 한다. 화면 전환 시 숫자 위치가 급히 움직이지 않도록 간단한 전환만 적용한다.

## 5. 주차 화면

속도·기어 영역은 같은 위치에 유지하되, 가운데와 오른쪽을 상세 카드로 확장한다. 차량 그림 대신 현재 수치가 있는 카드와 핸들 각도 도형으로 채운다.

- 배터리 카드: SOC를 크게, HV 전압·전류를 함께 표시.
- 차량 카드: 연료량·냉각수 온도·모듈 전압·외기 온도.
- 조향 카드: 회전하는 핸들 도형과 부호 있는 각도. 중앙 오차가 있으므로 '완전 정렬' 판정은 하지 않는다.
- 하단: '화면 꾸미기', '연결 관리'.

카드를 누르면 설명·단위·마지막 수신 시각을 보여준다. 배터리 카드는 세 수치를 한 요청에서 받는다는 점을 활용해 같은 갱신 시각을 적용한다.

## 6. 화면 꾸미기

주행·주차 배치를 별도로 저장한다. 첫 버전은 고정 슬롯을 사용한다.

1. 주행 또는 주차 편집 대상을 선택한다.
2. 프리셋을 고른다.
3. 가운데 집중 항목과 오른쪽 보조 카드의 종류·순서를 바꾼다. 카드 중복은 막는다.
4. 글자 크기 '기본/크게', 주간/야간 테마를 선택한다.
5. 미리보기 후 저장한다. 취소하면 이전 설정을 복원한다.

속도·기어·연결 상태는 고정한다. 설정은 localStorage에 저장하며 기본값 복원 버튼을 둔다. 배치 변경은 선택 중인 화면에 즉시 미리보기로 반영하고 저장 전후를 구분한다.

P와 속도 0이 모두 신선하게 수신된 상태에서 실제 연결 화면 편집을 허용한다. 주행으로 전환되거나 상태가 불명확해지면 편집을 닫고 마지막 저장 배치로 돌아간다. 데모에서는 화면에 '데모'를 계속 표시하고 자유롭게 편집한다.

## 7. 데이터 UX

- 미수신: '--'와 항목명·단위만 표시.
- 정상 수신: 현재 수치 표시.
- 갱신 지연: 마지막 값에 '갱신 지연'을 붙이고 정상 표시와 구분.
- 연결 해제: 주요 실시간 계기는 '--'로 전환. 상세에서만 마지막 값과 수신 시각 확인 가능.
- 기어 정보 지연: 0 km/h만으로 P를 추정하지 않는다. 편집은 잠그고 기어 상태 확인 중으로 안내한다.
- 재연결: 각 항목이 새 응답을 받은 뒤에만 정상 표시로 복귀한다.

stale 판정은 항목별 폴링 주기에 맞춘다. 속도와 10초 단위 외기온에 같은 제한 시간을 사용하지 않는다. 최초 임계값은 목표 폴링 주기와 실제 갱신 간격을 보고 정하며, 제조사 경고로 오인할 임의의 온도·전압 경고는 넣지 않는다.

## 8. 차량 없이 개발·시연하는 흐름

기록된 응답은 파서 검증에 사용하고, 동작하는 화면에는 별도 데모 공급기를 둔다. 데모 시나리오는 '주차 → D → 속도/RPM 변화 → D에서 속도 0 → P'다. 연결 끊김과 특정 항목 갱신 지연도 선택해 재현한다. 데모 값은 실제 측정 로그와 혼합하지 않고 사용자가 어떤 모드인지 항상 알 수 있게 한다.

초기 순서는 주행/주차 정적 화면 → 데모 전환 → 커스텀 저장 → 수신 상태 UX → 실제 통신 연결이다. 이 문서는 화면·흐름 초안이며 아직 앱 코드와 시각 디자인을 구현한 것은 아니다.
